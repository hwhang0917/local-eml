# How to open .eml files on Windows and Mac

An `.eml` file is one email message saved as a file: headers, body and attachments together. You get them when a mail program saves a message, when someone forwards a message as an attachment, or when a backup tool exports a mailbox one message per file.

Windows and macOS can open a single `.eml` in a mail client if one is set up. For a folder of them, or when you don't want to add anything to a mail account, use a viewer instead.

## Open .eml files with Local Eml

1. Download Local Eml for your system from the [latest release](https://github.com/hwhang0917/local-eml/releases/latest) and open it. See [Install](../install) for the first-run prompts on Windows and macOS.
2. A browser window opens with the **Import** page. Drag your `.eml` files, or the whole folder, onto it. A `.zip` of `.eml` files works too.
3. Open the **Library** page. Every message is listed by date, with sender and subject. Click one to read it.

Attachments are listed under the message, with previews for images, PDFs, audio and video. HTML messages render with remote images blocked, so nothing is loaded from the sender's server unless you ask.

## Searching a folder of .eml files

Type in the search box to match sender, subject or body across every imported message. Korean text and 초성검색 work too. See [Searching](../search).

## Keep them or not

Imported messages are copied into Local Eml's library folder; your original files are untouched. If you only want to look and leave nothing behind, turn on [temporary sessions](../privacy#temporary-sessions) first.

## Other formats

Local Eml also opens `.mbox` files from [Google Takeout](./takeout-mbox), Thunderbird and Apple Mail, and Outlook [`.pst` files](./pst-without-outlook).
