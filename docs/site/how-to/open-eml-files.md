# How to open .eml files on Windows and Mac

An `.eml` file is a single email saved as a file, with its text and attachments inside. You usually end up with them when you save a message from a mail app, when someone forwards an email as an attachment, or when a backup tool exports a mailbox one message at a time.

If you have a mail app set up, Windows and macOS can open a single `.eml` file in it. For a whole folder of them, or if you don't want to add them to a mail account, a viewer like Local Eml is easier.

## Open .eml files with Local Eml

1. Download Local Eml for your system from the [latest release](https://github.com/hwhang0917/local-eml/releases/latest) and open it. If Windows or macOS shows a warning the first time, [Install](../install) explains what to do.
2. A browser window opens on the **Import** page. Drag your `.eml` files, or the folder they're in, onto it. A `.zip` of `.eml` files works too.
3. Go to the **Library** page. Every message is listed by date, with the sender and subject. Click one to read it.

Attachments are listed under the message, and images, PDFs, audio, video, Hangul (HWP, HWPX), Word (DOCX) and Excel (XLSX, XLS) files can be previewed. Previews are drawn inside the app, so documents never leave your computer. Images hosted on the internet aren't loaded unless you click to load them, so the sender can't tell you opened the message.

## Search a folder of .eml files

Type in the search box to look through the sender, subject and body of every imported message. Korean text and 초성검색 work too. See [Searching](../search).

## Keep them, or leave nothing behind

Importing copies the messages into Local Eml's own folder. Your original files aren't changed. If you only want to look and not keep anything, turn on [temporary sessions](../privacy#temporary-sessions) first.

## Other formats

Local Eml also opens `.mbox` files from [Google Takeout](./takeout-mbox), Thunderbird and Apple Mail, and Outlook [`.pst` files](./pst-without-outlook).
