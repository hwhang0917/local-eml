# Outlook 없이 .pst 파일 열기

`.pst`는 Outlook 전용 메일함 보관 파일입니다. 보통은 Outlook이 설치되어 있고 연결할 계정이 있어야 열 수 있습니다. Local Eml은 `.pst`를 직접 읽으므로 macOS와 Linux를 포함한 어느 PC에서든 오래된 보관 파일을 둘러볼 수 있습니다.

## .pst 파일은 어디서 생기나요

- Outlook의 **파일 → 열기 및 내보내기 → 가져오기/내보내기 → 파일로 내보내기 → Outlook 데이터 파일(.pst)**
- Outlook 자동 보관 기능이 만든 보관 파일. 보통 `문서\Outlook 파일`에 있습니다.
- IT 부서나 이전 직장에서 넘겨받은 메일함 내보내기

## Local Eml에서 열기

1. Local Eml을 열고 **가져오기**로 갑니다.
2. `.pst` 파일을 페이지에 끌어다 놓거나 파일 선택기로 고릅니다.
3. 가져오기가 끝날 때까지 기다립니다. 모든 메일이 첨부파일과 함께 라이브러리의 `.eml` 파일이 됩니다.

`.pst` 안의 폴더 구조는 폴더로 유지되지 않습니다. 메일은 한 목록에 나오며 검색, 날짜 범위, 보낸 사람으로 찾거나 카테고리를 붙여 정리합니다.

## 되지 않는 것

- **`.ost` 파일**은 보관 파일이 아니라 실시간 메일함의 캐시이며 지원하지 않습니다. Outlook에서 `.pst`로 내보내세요.
- **Outlook.com 계정의 IMAP.** Microsoft가 Outlook.com 메일함의 비밀번호 로그인을 막았기 때문에 Local Eml의 IMAP 가져오기로는 연결할 수 없습니다. Outlook 데스크톱 앱에서 `.pst`로 내보내는 것이 확실한 방법입니다.

`.pst` 가져오기가 실패하면 가져오기 로그의 오류 내용을 담아 [이슈](https://github.com/hwhang0917/local-eml/issues)를 열어 주세요. 파일 자체는 첨부하지 마세요.
