# Outlook 없이 .pst 파일 열기

`.pst`는 Outlook 메일함을 파일로 저장한 것입니다. 보통은 Outlook이 있어야 열 수 있습니다. Local Eml은 `.pst` 파일을 직접 읽을 수 있어서, Mac이나 Linux를 포함해 어떤 컴퓨터에서든 예전 메일을 볼 수 있습니다.

## .pst 파일은 어디서 생기나요

- Outlook에서 내보낸 경우: **파일 → 열기 및 내보내기 → 가져오기/내보내기 → 파일로 내보내기 → Outlook 데이터 파일(.pst)**
- Outlook의 자동 보관 기능이 만든 파일. 보통 `문서\Outlook 파일`에 있습니다.
- 회사 IT 부서나 이전 직장에서 메일함을 넘겨받은 경우

## Local Eml에서 열기

1. Local Eml을 열고 **가져오기**로 갑니다.
2. `.pst` 파일을 화면에 끌어다 놓거나 클릭해서 고릅니다.
3. 가져오기가 끝날 때까지 기다립니다. 모든 메일이 첨부파일과 함께 라이브러리에 `.eml` 파일로 저장됩니다.

`.pst` 안의 폴더 구분은 유지되지 않습니다. 모든 메일이 한 목록에 나오므로 검색, 날짜, 보낸 사람으로 찾으면 됩니다. 분류를 지정해 직접 정리할 수도 있습니다.

## 안 되는 것

- **`.ost` 파일.** Outlook이 사용 중인 메일함을 임시로 복사해 둔 파일이라 보관용이 아니며, Local Eml에서 열 수 없습니다. Outlook에서 `.pst`로 내보내세요.
- **Outlook.com 계정의 IMAP 연결.** Microsoft가 Outlook.com 메일함에 비밀번호로 로그인하는 것을 막았기 때문에 Local Eml의 IMAP 가져오기로는 연결되지 않습니다. Outlook 데스크톱 앱에서 `.pst`로 내보내세요.

`.pst`를 가져오다 실패하면 가져오기 화면에 나온 오류 메시지를 적어 [이슈](https://github.com/hwhang0917/local-eml/issues)를 올려 주세요. 파일 자체는 내 메일이 들어 있으니 첨부하지 마세요.
