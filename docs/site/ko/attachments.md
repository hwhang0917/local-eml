# 첨부파일 둘러보기

**첨부파일** 화면에는 모든 메일의 첨부파일이 한 표에 모여 있습니다. 어떤 메일에 붙어 왔는지 기억나지 않아도 파일을 찾을 수 있고, 어떤 파일이 용량을 많이 차지하는지도 한눈에 볼 수 있습니다.

서명에 들어간 로고처럼 본문 안에 표시되는 이미지는 첨부파일이 아니라서 목록에 나오지 않습니다. 스팸이나 피싱으로 표시한 메일의 첨부파일도 나오지 않습니다.

![첨부파일 화면](https://hwhang0917.github.io/local-eml/img/ko/attachments.webp)

## 파일 찾기

- **파일 이름 검색**: 파일 이름의 일부만 입력해도 찾습니다. `계약`을 입력하면 `계약서_최종.pdf`와 `임대계약_부록.hwp`가 나옵니다.
- **보낸 사람으로 거르기**: 보낸 사람의 이름이나 주소 일부로 거릅니다.
- **파일 형식**: 이미지, PDF, 문서, 스프레드시트, 압축 파일, 오디오·비디오, 기타 중에서 고릅니다. 항목마다 해당하는 파일 수가 함께 표시됩니다. 형식은 메일에 적힌 파일 종류를 보고 정하고, 종류가 적혀 있지 않으면 확장자를 봅니다. 한글 문서(`.hwp`, `.hwpx`)는 문서로 분류됩니다.
- **기간**: 메일을 보낸 날짜로 거릅니다.

열 제목을 누르면 이름, 형식, 크기, 날짜, 보낸 사람 순으로 정렬됩니다. 크기를 큰 순서로 정렬하면 용량을 많이 차지하는 파일부터 볼 수 있습니다. 조건에 맞는 파일 수와 전체 크기는 화면 제목 옆에 나옵니다.

## 파일 열기

줄마다 버튼이 최대 세 개 있습니다.

- **새 탭에서 열기**: 이미지, PDF, 오디오, 동영상, 텍스트 파일을 브라우저에서 엽니다. 그 밖의 파일은 브라우저에서 안전하게 열 수 없어서 다운로드 버튼만 있습니다.
- **다운로드**: 파일을 저장합니다.
- **이메일로 이동**: 파일이 붙어 온 메일을 **첨부파일** 탭으로 엽니다. 미리 볼 수 있는 파일이면 미리보기가 이미 열려 있습니다. 한글, 워드, 엑셀 파일은 이름을 클릭해도 내려받는 대신 이곳으로 이동합니다.

파일 이름을 누르면 **새 탭에서 열기**와 같고, 열 수 없는 파일이면 내려받습니다.

## 업데이트한 뒤

목록은 메일을 가져올 때 만들어집니다. 이전 버전에서 가져온 메일은 새 버전을 처음 실행할 때 백그라운드에서 추가됩니다. 메일이 많으면 목록에 나타나기까지 잠시 걸릴 수 있습니다.
