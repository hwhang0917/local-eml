# 검색과 탐색

라이브러리 페이지가 홈 화면입니다. 메일 목록과 검색, 필터가 있고 한 번 클릭하면 읽기 화면이 열립니다.

![라이브러리](https://hwhang0917.github.io/local-eml/img/ko/library.webp)

## 전문 검색

검색창은 보낸 사람, 제목, 본문을 한 번에 검색합니다. 한글을 비롯한 CJK 언어도 바로 검색되며, 색인은 SQLite FTS5로 만듭니다.

### 초성검색

한글 음절의 초성만 입력하면 그 초성으로 시작하는 단어를 모두 찾습니다. `ㅎㄱ`은 `한국`을, `ㅇㅁ`은 `이메일`을 찾습니다. 라이브러리 전체에서 동작합니다.

![검색 결과](https://hwhang0917.github.io/local-eml/img/ko/search.webp)

## 필터

- **별표**: 별표한 메일만 봅니다.
- **카테고리**: 정해진 색상 묶음에 **설정 → 카테고리**에서 이름을 붙일 수 있습니다. 목록이나 뷰어에서 지정한 뒤 필터로 걸러 보세요.
- **날짜 범위**: 두 날짜 사이에 보낸 메일만 봅니다.
- **대화별로 묶기**: 각 스레드를 가장 최근 메일 하나로 접고, 건수를 눌러 펼칠 수 있습니다.

## 읽기

HTML 메일은 격리된 프레임 안에 표시됩니다. 외부 이미지는 기본적으로 차단되어 자리 표시로 보이며, 한 번 클릭하면 그 메일에서만 불러옵니다. 링크는 실제 이동 주소를 보여 주는 확인 창을 거쳐 새 탭에서 열립니다.

첨부파일은 이미지, PDF, 오디오, 비디오, 텍스트는 미리보기로, 그 외는 내려받기로 제공됩니다.

## 성능

목록 탐색과 검색은 메일 10만 건을 훌쩍 넘어도 사실상 바로 응답합니다. 라이브러리가 커질수록 느려지는 것은 **대화별로 묶기** 하나뿐이며, 아주 큰 라이브러리에서는 한 페이지에 1초 정도 걸릴 수 있습니다. 굼뜨게 느껴지면 묶기 토글을 끄세요.

| 작업 | 메일 1만 건 | 메일 10만 건 |
|---|---|---|
| 목록 탐색 / 페이지 이동 | 1 ms 미만 | 1 ms 미만 |
| 검색 (일반적인 검색어) | 1 ms 미만 | 약 2 ms |
| 초성검색 | 약 5 ms | 약 50 ms |
| 대화별로 묶은 목록 | 약 85 ms | 약 0.9초 |

중급 노트북에서 가상 라이브러리로 측정했으며, 전체 건수 집계를 포함한 50건 한 페이지 기준입니다.
