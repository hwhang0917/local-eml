# 설정과 명령어

## 설정

위쪽 메뉴에서 **설정**을 여세요. 메뉴 오른쪽의 책 아이콘을 누르면 이 사용 설명서가 새 탭에서 열립니다.

| 메뉴 | 할 수 있는 일 |
|---|---|
| **정보** | 버전을 보고 업데이트를 확인합니다. 백그라운드 서비스로 설치했다면 여기서 바로 업데이트할 수 있습니다. **라이브러리 다시 검사**는 데이터 폴더에 있지만 라이브러리에 아직 없는 `.eml` 파일을 찾아 추가합니다. 이 사용 설명서, GitHub, 문제 신고 페이지로 가는 링크도 있습니다. |
| **분류** | 색깔별 분류에 이름을 붙입니다. |
| **언어 및 지역** | 화면 언어와, 날짜를 "2024년 3월 3일"처럼 보일지 "2년 전"처럼 보일지 고릅니다. |
| **읽음 표시** | 읽음 표시 기능을 켭니다(기본은 꺼짐). 켜면 안 읽은 메일 제목이 굵게 나오고, 메일을 열면 읽음으로 바뀝니다. 목록에는 **안 읽음** 필터와 줄마다 읽음/안 읽음 버튼이 생깁니다. 처음 켤 때 기존 메일을 읽음으로 둘지 안 읽음으로 둘지 고릅니다. 한꺼번에 많이 가져온 뒤에는 **모두 읽음으로 표시**로 정리하세요. |
| **백업 복원** | 내보낸 `.zip`에서 별표, 분류, 설정, 프로필을 되살립니다. |
| **중복 메일** | Takeout `.mbox`를 가져온 뒤 같은 계정을 IMAP으로 동기화한 경우처럼 여러 번 저장된 메일을 찾아 하나만 남깁니다. 별표, 읽음 상태, 분류는 남는 사본으로 옮겨집니다. [중복 메일](./import#중복-메일) 참고. |
| **스팸·피싱** | 표시한 메일을 보고, 피싱 경고를 켜거나 끕니다. |
| **개인정보** | 임시 세션, 모든 데이터 삭제, 저장된 IMAP 비밀번호의 암호화 키가 있는 곳 |
| **오픈소스 라이선스** | Local Eml이 쓰는 오픈소스 라이브러리의 라이선스 |

## 명령어

평소에 쓸 때는 명령어가 필요 없습니다. 백그라운드 서비스를 관리하거나 스크립트에서 쓸 때 참고하세요.

```text
local-eml <command> [flags]

  app [--ephemeral]        브라우저 창으로 열기. 창을 닫으면 종료 (기본값)
  serve [--port 7878] [--ephemeral]
                           로컬 웹 서버 실행 (내 컴퓨터에서만 접속 가능)
  install [-y|--yes] [--port 7878]
                           로그인할 때 백그라운드로 시작 (systemd/launchd/Windows 시작 프로그램)
  uninstall [-y|--yes]     백그라운드 서비스 중지 및 등록 해제
  token                    API와 브라우저에 필요한 세션 토큰 출력
  version | -V | --version
```

명령 없이 실행하면 `app`과 같습니다. 더블클릭했을 때 이렇게 실행됩니다.

`serve`를 `--port` 없이 실행했는데 다른 프로그램이 이미 7878 포트를 쓰고 있으면, 비어 있는 다음 포트로 옮겨 갑니다(7897까지). 어느 포트를 골랐는지는 로그에 남습니다. 백그라운드 서비스도 다른 포트를 지정해 설치하지 않았다면 똑같이 동작합니다. `--port`를 직접 지정하면 그 포트만 쓰고, 이미 사용 중이면 오류를 내고 멈춥니다. [7878 포트를 이미 다른 프로그램이 쓰고 있어요](./troubleshooting#_7878-포트를-이미-다른-프로그램이-쓰고-있어요)를 참고하세요.

`install`과 `uninstall`은 실행 전에 한 번 더 묻습니다. 스크립트에서는 `--yes`를 붙이면 묻지 않습니다.

## 세션 토큰

Local Eml에는 내 컴퓨터에서만 접속할 수 있지만, 같은 컴퓨터의 다른 프로그램이나 다른 사용자 계정도 여기에 포함됩니다. 그래서 토큰을 한 번 더 확인합니다. 토큰은 무작위로 만든 비밀번호로, 데이터 폴더의 `session-token` 파일에 저장되며 나만 읽을 수 있습니다.

- 더블클릭으로 열면 자동으로 로그인됩니다. 프로그램은 토큰 자체가 아니라, 토큰으로 만든 일회용 로그인 링크를 브라우저에 넘겨줍니다. 마지막으로 사용한 뒤 30일 동안 로그인 상태가 유지됩니다.
- 브라우저에서 주소를 직접 열면 처음 한 번 로그인 화면이 나옵니다. 명령 프롬프트나 터미널을 여는 방법과 `local-eml token` 명령을 복사하는 **복사** 버튼이 있으니, 명령을 실행해 나온 토큰을 붙여 넣으세요.
- 스크립트에서는 헤더로 보냅니다. `curl -H "Authorization: Bearer $(local-eml token)" http://127.0.0.1:7878/api/stats`

[임시 세션](./privacy#임시-세션)은 토큰이 따로 있지만, 더블클릭으로 열면 마찬가지로 알아서 처리됩니다.

## 환경 변수

| 변수 | 하는 일 |
|---|---|
| `LOCAL_EML_PORT` | 설치 스크립트가 등록할 포트. 기본값 `7878` |
| `LOCAL_EML_SYNC_INTERVAL` | 백그라운드 동기화로 새 IMAP 메일을 확인하는 간격. 예: `5m`, `off`. 앱에서 정한 값이 우선 |
| `LOCAL_EML_EPHEMERAL` | `1`이면 [임시 세션](./privacy#임시-세션)으로 시작. 백그라운드 서비스는 무시 |
| `LOCAL_EML_KEYRING` | `off`이면 IMAP 비밀번호 암호화 키를 시스템 보안 저장소 대신 파일에 둡니다. 이미 보안 저장소에 있었다면 파일로 다시 옮깁니다. [비밀번호는 어떻게 되나요](./sync#비밀번호는-어떻게-되나요) 참고 |
| `LOCAL_EML_LOG_LEVEL` | `debug`, `info`, `warn`, `error` 중 하나. 기본값 `info` |

백그라운드 서비스에 적용하려면 서비스 설정에 넣어야 합니다. Linux는 systemd 유닛, macOS는 LaunchAgent plist, Windows는 서비스 설정입니다.

## 데스크톱 전용

창 너비가 640픽셀 이상이면 됩니다. 세로로 세운 모니터나 화면 절반에 붙인 창에서도 쓸 수 있습니다. 창이 좁으면 목록의 일부 열이 빠집니다. 라이브러리는 크기 열을 숨기고 날짜를 시간 없이 보여 주며(날짜에 마우스를 올리면 전체 날짜가 보입니다), 첨부파일 목록은 메일 열부터 숨기고, 더 좁아지면 형식과 크기 열도 숨깁니다. 640픽셀보다 좁으면 창을 넓혀 달라는 안내가 나옵니다. 어차피 내 컴퓨터에서만 접속할 수 있어서 휴대폰으로는 열 수 없습니다.
