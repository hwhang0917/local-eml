# 설정과 명령줄

## 설정 페이지

| 페이지 | 내용 |
|---|---|
| **정보** | 버전, 업데이트 확인, 서비스 설치에서는 그 자리에서 업데이트 |
| **카테고리** | 정해진 색상 묶음에 이름 붙이기 |
| **언어와 날짜** | 인터페이스 언어, 절대·상대 날짜 표시 |
| **읽음 표시** | 기본은 꺼짐. 켜면 안 읽은 메일 제목이 굵게 표시되고, 메일을 열면 읽음으로 바뀌며, 목록에 **안 읽음** 필터와 행별 토글이 생깁니다. 처음 켤 때 기존 메일을 읽음으로 둘지 안 읽음으로 둘지 고르고, 대량 가져오기 뒤에는 **모두 읽음으로 표시**로 한 번에 정리할 수 있습니다 |
| **백업에서 복원** | 내보낸 `.zip`에서 별표, 카테고리, 설정, 프로필 되살리기 |
| **스팸·피싱** | 표시한 메일 목록과 피싱 경고 스위치 |
| **개인정보** | 임시 세션과 모든 데이터 삭제 |
| **오픈소스 라이선스** | 사용된 오픈소스 라이브러리의 라이선스 |

## 명령줄

```text
local-eml <command> [flags]

  app [--ephemeral]        브라우저 창으로 열기. 창을 닫으면 종료 (기본값)
  serve [--port 7878] [--ephemeral]
                           로컬 웹 서버 실행 (내 PC에서만 접속)
  install [-y|--yes] [--port 7878]
                           백그라운드 서비스로 등록 (systemd/launchd/Windows 서비스)
  uninstall [-y|--yes]     백그라운드 서비스 중지 및 등록 해제
  version | -V | --version
```

인수 없이 실행하면 `app`과 같습니다. 더블클릭이 바로 그 동작입니다.

`install`과 `uninstall`은 확인을 묻습니다. 스크립트에서는 `--yes`로 생략할 수 있습니다.

## 환경 변수

| 변수 | 효과 |
|---|---|
| `LOCAL_EML_PORT` | 설치 스크립트가 등록할 포트. 기본값 `7878` |
| `LOCAL_EML_SYNC_INTERVAL` | IMAP 백그라운드 동기화 간격. 예: `5m`, 또는 `off`. 앱에서 저장한 값이 우선 |
| `LOCAL_EML_EPHEMERAL` | `1`이면 [임시 세션](./privacy#임시-세션)으로 시작. 서비스에서는 무시 |
| `LOCAL_EML_LOG_LEVEL` | `debug`, `info`, `warn`, `error`. 기본값 `info` |

서비스에서는 서비스 환경에 지정하세요. systemd 유닛, LaunchAgent plist, 또는 Windows 서비스 설정입니다.

## PC 전용

인터페이스는 폭 약 768픽셀 이상의 창이 필요합니다. 그보다 좁으면 깨진 화면 대신 창을 넓혀 달라는 안내를 보여 줍니다. 서버가 내 PC에서만 듣기 때문에 휴대폰에서는 어차피 접속할 수 없습니다.
