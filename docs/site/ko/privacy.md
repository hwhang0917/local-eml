# 개인정보와 데이터

## 데이터는 어디에 있나요

모든 데이터는 폴더 하나에 있습니다. Linux와 macOS는 `~/.local-eml/`, Windows는 `%USERPROFILE%\.local-eml\`입니다.

| 경로 | 들어 있는 것 |
|---|---|
| `eml/` | 메일 (`.eml` 파일 그대로) |
| `db/local-eml.db` | 데이터베이스: 메일 정보, 검색 색인, 프로필, 설정 |
| `logs/local-eml.log` | 로그 파일. 메일 제목과 주소가 들어 있습니다. 자정마다 그날 로그는 `local-eml-YYYY-MM-DD.log`로 옮겨지고, 30일이 지난 로그는 삭제됩니다 |
| `keys/secret.key` | 저장된 IMAP 비밀번호를 암호화하는 키 (시스템 보안 저장소가 없을 때). 보안 저장소가 있으면 키는 자격 증명 관리자, 키체인, Linux Secret Service에 `local-eml` 이름으로 있고, `keys/`에는 그렇다는 안내 파일만 남습니다 |
| `session-token` | 브라우저가 로그인할 때 쓰는 비밀번호. [세션 토큰](./settings-cli#세션-토큰) 참고 |
| `prefs.json` | 실행 설정 (지금은 임시 세션 스위치 하나뿐) |

이 폴더는 같은 컴퓨터의 다른 사용자 계정이 열어 볼 수 없게 만들어집니다.

## 네트워크

Local Eml은 내 컴퓨터(`127.0.0.1`)에서 오는 접속만 받습니다. 같은 네트워크의 다른 기기는 접속할 수 없고, 브라우저에 열려 있는 다른 웹사이트도 Local Eml에 요청을 보낼 수 없습니다. 인터넷에 연결하는 것은 내가 시킬 때뿐입니다. IMAP·S3에서 가져오거나 내보낼 때, 그리고 **설정 → 정보**에서 업데이트를 확인할 때입니다.

## 비밀번호와 키

- S3 시크릿 키와 세션 토큰은 저장하지 않습니다.
- IMAP 비밀번호는 프로필에서 백그라운드 동기화를 켰을 때만 암호화해서 저장합니다. 암호화 키는 시스템 보안 저장소(자격 증명 관리자, 키체인, Linux Secret Service)에 두고, 보안 저장소가 없으면 파일에 둡니다. [새 메일 받기](./sync#비밀번호는-어떻게-되나요)를 참고하세요.
- 서버 주소, 버킷 이름, 사용자 이름, 액세스 키 ID는 비밀 정보가 아니므로 암호화하지 않고 저장합니다.

## 임시 세션

`.eml` 파일 몇 개를 잠깐 열어 보고, 아무것도 남기고 싶지 않을 때 쓰는 기능입니다.

**설정 → 개인정보 → 더블클릭 실행을 임시 세션으로**를 켜세요. 다음 실행부터는 더블클릭할 때마다 임시 폴더에 빈 라이브러리를 만들어 시작하고, 앱을 닫으면 그 폴더를 지웁니다. 앱이 비정상적으로 꺼졌다면 다음에 실행할 때 남은 폴더를 지웁니다. 임시 세션일 때는 화면 위쪽에 안내 배너가 나옵니다.

디스크에 남는 것은 이 스위치가 켜져 있다는 것만 기억하는 `prefs.json` 하나입니다. 메일이나 비밀번호는 들어 있지 않습니다.

임시 창에서 작업한 내용을 남기고 싶다면, 그 창에서 스위치를 끄거나 같은 페이지의 **이 창의 메일 남기기**를 체크하세요. 창을 닫을 때 메일, 별표, 읽음 표시, 분류가 삭제되지 않고 기존 라이브러리에 추가됩니다. 이미 라이브러리에 있던 메일은 원래 표시를 그대로 유지하고, 저장한 프로필은 비밀번호 없이, 백그라운드 동기화가 꺼진 상태로 옮겨집니다. 닫을 때 끝내지 못하면 다음 실행 때 마저 옮깁니다.

백그라운드 서비스가 실행 중일 때는 이 스위치를 쓸 수 없습니다. 서비스는 꺼지지 않기 때문입니다. 이럴 때는 서비스를 멈추거나, Local Eml을 `--ephemeral` 옵션으로 실행하세요(`LOCAL_EML_EPHEMERAL=1`도 같습니다). 서비스의 라이브러리와는 별개인 임시 세션이 열립니다.

## 모든 데이터 삭제

**설정 → 개인정보 → 지금 모든 데이터 삭제**를 누르면 모든 메일, 검색 색인, 가져오기 기록, 로그가 지워집니다. 라이브러리가 다시 채워지지 않도록 백그라운드 동기화도 꺼집니다. 프로필(비밀번호 제외), 분류, 설정, 암호화 키는 남습니다. 실수로 지우지 않도록 확인 단어를 입력해야 실행됩니다.

::: warning 복구 불가능을 보장하지 않습니다
임시 세션과 모든 데이터 삭제는 직접 파일을 지울 때와 같은 방식으로 지웁니다. 흔적까지 완전히 없애는 보안 삭제가 아닙니다. 지운 파일은 특히 SSD에서 복구되는 경우가 많고, Local Eml은 복구할 수 없다고 보장하지 않습니다. 반대로 Local Eml이 지운 데이터를 되살려 줄 수도 없으니, 필요한 데이터는 따로 백업해 두세요. Local Eml의 다른 기능과 마찬가지로 이 기능도 [GPL v3](https://github.com/hwhang0917/local-eml/blob/main/LICENSE)에 따라 아무런 보증 없이 제공됩니다.
:::
