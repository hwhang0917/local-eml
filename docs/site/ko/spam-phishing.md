# 스팸과 피싱

Local Eml에는 서로 다른 두 가지 도구가 있습니다. 자동으로 계산되는 경고와, 사용자가 직접 붙이는 표시입니다.

## 피싱 경고

모든 메일을 오프라인에서 검사해 피싱의 구조적 징후를 찾습니다. 키워드 목록은 없고 어디로도 전송하지 않습니다. 검사하는 신호는 다음과 같습니다.

- 링크 텍스트와 실제 이동 주소의 사이트가 다름
- IP 주소로 바로 가는 링크
- 유사 도메인 또는 비ASCII 도메인
- 메일 헤더의 SPF, DKIM, DMARC 실패
- 보낸 사람과 다른 사이트로 향하는 Reply-To
- 다른 사이트의 주소를 끼워 넣은 표시 이름
- 실행 파일 또는 스크립트 첨부
- 본문의 입력 양식이나 비밀번호 입력란

하나라도 해당하면 뷰어에 노란 배너가, 목록에 경고 아이콘이 표시됩니다. 경고일 뿐 판정이 아니며, 자동으로 숨기지는 않습니다.

괜찮은 메일인 것이 확실하면 배너나 표시 메뉴에서 **스팸 아님**을 선택하세요. 그 메일의 경고만 사라집니다. 경고를 모두 끄려면 **설정 → 스팸·피싱**에서 끄세요.

## 메일에 표시 붙이기

뷰어의 방패 아이콘으로 메일을 **스팸** 또는 **피싱**으로 표시합니다. 표시된 메일은

- 라이브러리와 대화 보기에서 숨겨집니다.
- 열어도 본문 텍스트만 보여 줍니다. HTML, 이미지, 첨부파일, 클릭 가능한 링크가 모두 비활성화됩니다. 서버가 해당 부분을 내려 주지 않으므로 페이지가 요청해도 그대로 유지됩니다.

**설정 → 스팸·피싱**에서 표시한 메일을 모두 볼 수 있고, 버튼으로 표시를 해제할 수 있습니다.
