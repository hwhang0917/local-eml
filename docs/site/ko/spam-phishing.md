# 스팸과 피싱

Local Eml은 피싱으로 보이는 메일에 경고를 띄우고, 직접 스팸이나 피싱으로 표시할 수 있게 해 줍니다. 둘은 별개의 기능입니다.

## 피싱 경고

모든 메일을 내 컴퓨터 안에서 검사해 흔한 피싱 징후를 찾습니다. 어디에도 전송하지 않고, 의심 단어 목록 같은 것도 쓰지 않습니다. 확인하는 항목은 다음과 같습니다.

- 링크에 보이는 사이트와 실제로 연결되는 사이트가 다름
- 사이트 이름 대신 IP 주소로 연결되는 링크
- 다른 사이트를 흉내 낸 주소, 또는 특이한 문자가 섞인 주소
- 메일 서버가 보낸 사람을 확인하는 검사(SPF, DKIM, DMARC)에 실패
- 답장이 보낸 사람과 다른 사이트로 가도록 되어 있음
- 보낸 사람 이름에 다른 사이트의 메일 주소가 들어 있음
- 실행 파일이나 스크립트 첨부
- 메일 본문에 입력 양식이나 비밀번호 입력란이 있음

하나라도 해당하면 메일을 열었을 때 노란 배너가, 목록에는 경고 아이콘이 나옵니다. 어디까지나 경고일 뿐이고, 메일을 자동으로 숨기지는 않습니다.

괜찮은 메일이 확실하면 배너나 표시 메뉴에서 **스팸 아님**을 고르세요. 그 메일의 경고만 사라집니다. 경고를 아예 끄려면 **설정 → 스팸·피싱**으로 가세요.

## 스팸이나 피싱으로 표시하기

메일을 읽다가 방패 아이콘을 누르면 **스팸** 또는 **피싱**으로 표시할 수 있습니다. 표시한 메일은

- 라이브러리와 대화 목록에서 보이지 않습니다.
- 열면 글자만 보입니다. 서식, 이미지, 첨부파일, 링크가 모두 꺼집니다. Local Eml이 이 부분을 아예 내주지 않기 때문에, 무언가가 요청하더라도 꺼진 상태가 유지됩니다.

**설정 → 스팸·피싱**에서 표시한 메일 목록을 보고 표시를 해제할 수 있습니다.
