# AI 에이전트 (MCP)

Claude Desktop, Claude Code처럼 이미 쓰고 있는 AI 에이전트가 Local Eml 보관함을 검색하고 읽게 할 수 있습니다. 에이전트가 도구에 연결하는 표준 방식인 [MCP](https://modelcontextprotocol.io)(Model Context Protocol)를 사용합니다. 설정해 두면 에이전트에게 이렇게 물어볼 수 있습니다.

- "집주인한테 온 임대차 갱신 메일 찾아서 뭐가 바뀌었는지 요약해 줘."
- "3월에 Northwind에서 온 청구서 합계가 얼마야? PDF까지 읽어 봐."
- "이삿짐 업체한테서 마지막으로 연락 온 게 언제고, 보증금에 대해 뭐라고 했어?"

**기본적으로 꺼져 있습니다.** **설정 → AI 에이전트**에서 켜세요.

::: danger 에이전트가 읽은 내용은 내 컴퓨터 밖으로 나갑니다
Local Eml 자체는 여전히 아무것도 외부로 보내지 않습니다. 하지만 에이전트가 읽는 모든 메일과 첨부파일은 그 에이전트의 AI 제공업체(예: Claude는 Anthropic, ChatGPT는 OpenAI)로 전송되며 해당 업체의 약관에 따라 처리됩니다. 이 메일을 맡겨도 될 만큼 믿을 수 있는 에이전트만 연결하세요. [Ollama](https://ollama.com) 등으로 로컬 모델을 쓰는 에이전트라면 내용이 내 컴퓨터에 남습니다.
:::

## 에이전트가 할 수 있는 일과 없는 일

에이전트는 읽기 전용 도구만 씁니다.

| 도구 | 하는 일 |
|---|---|
| `search_emails` | [검색창과 같은 연산자](./search)(`from:`, `subject:`, `after:`, `has:attachment` 등)로 검색 |
| `read_email` | 메일 하나 읽기: 헤더, 본문, 첨부파일 목록 |
| `get_thread` | 같은 대화에 속한 나머지 메일 나열 |
| `list_attachments` | 이름, 종류, 보낸 사람, 날짜로 보관함 전체의 첨부파일 찾기 |
| `read_attachment` | PDF, Word(`.docx`), Excel(`.xlsx`), PowerPoint(`.pptx`), 한글(`.hwp`, `.hwpx`), OpenDocument, HTML, 텍스트 파일의 내용 읽기 |

에이전트는 메일을 삭제하거나 수정, 별표, 이동, 발송할 수 **없습니다**. [스팸·피싱](./spam-phishing)으로 표시한 메일은 검색에서 계속 숨겨지고, 첨부파일도 읽을 수 없습니다.

이미지, 스캔한 PDF, 예전 바이너리 Office 형식(`.doc`, `.xls`, `.ppt`)은 에이전트가 읽을 텍스트가 없습니다. 암호가 걸린 파일도 읽을 수 없습니다.

::: tip 메일에 AI를 노린 지시가 들어 있을 수 있습니다
누구나 "이전 지시는 무시하고 …"라고 쓴 메일을 보낼 수 있습니다. Local Eml은 에이전트에게 메일을 데이터로만 다루라고 알려 주고, 도구로는 아무것도 바꿀 수 없습니다. 하지만 다른 도구(브라우저, 내 파일)도 가진 에이전트는 속을 수 있으니, 낯선 메일을 읽은 뒤 에이전트가 하는 일을 지켜보세요.
:::

## 에이전트 연결하기

**설정 → AI 에이전트**를 켜면 에이전트 종류별 설정 방법과 **복사** 버튼이 나옵니다.

### Claude Desktop

1. Claude Desktop에서 **설정 → 개발자 → 구성 편집**을 엽니다.
2. Local Eml에서 복사한 설정을 `claude_desktop_config.json`에 붙여 넣습니다. 이미 `"mcpServers"`가 있다면 그 안에 `"local-eml"` 항목을 추가하세요.
3. Claude Desktop을 완전히 종료했다가 다시 엽니다.

이 설정은 `local-eml mcp`라는 작은 중계 프로그램을 실행합니다. 중계 프로그램이 데이터 폴더에서 에이전트 토큰을 읽고 Local Eml이 쓰는 포트도 알아서 찾기 때문에, 설정 파일에 비밀값이 들어가지 않고 토큰을 새로 만들어도 그대로 동작합니다. Local Eml이 실행 중이어야 합니다(백그라운드 서비스 또는 앱 실행).

Local Eml이 WSL 안에서 실행되고 Claude Desktop은 Windows에서 실행된다면, 설정 페이지가 `wsl.exe`를 거쳐 실행하는 설정을 보여 줍니다. 그대로 붙여 넣으세요.

### Claude Code

설정 페이지의 명령을 터미널에서 한 번 실행하세요.

```sh
claude mcp add --transport http local-eml http://127.0.0.1:7878/mcp --header "Authorization: Bearer <토큰>"
```

### 기타 에이전트

- HTTP로 연결하는 에이전트("streamable HTTP" 전송 방식)는 `http://127.0.0.1:7878/mcp` 주소를 쓰고, `Authorization: Bearer <토큰>` 헤더로 토큰을 보냅니다.
- MCP 서버를 명령어로 실행하는 에이전트(stdio)는 `local-eml mcp`를 실행합니다. Local Eml이 평소 포트에 없어서 찾지 못하면 `--port N`을 붙이세요.

URL은 Local Eml이 쓰는 포트 기준입니다. 7878 포트가 사용 중이라 다른 포트로 바뀌었다면 설정에서 URL을 다시 복사하세요. `local-eml mcp` 명령은 포트를 알아서 찾습니다.

## 에이전트 토큰

에이전트 토큰은 [세션 토큰](./settings-cli#세션-토큰)과 별개의 비밀번호입니다. 읽기 전용 에이전트 도구만 열 수 있고 Local Eml의 나머지 기능은 열 수 없으며, 브라우저 로그인으로는 에이전트 도구에 접근할 수 없습니다.

- **보기**를 누르면 토큰이 보입니다. 설정 명령의 복사 버튼은 토큰까지 함께 복사합니다.
- **새 토큰 만들기**를 누르면 즉시 바뀝니다. HTTP로 연결하는 에이전트에는 새 토큰을 다시 붙여 넣어야 합니다. Claude Desktop 설정은 알아서 새 토큰을 읽습니다.
- 에이전트 접근을 끄면 다음 요청부터 모든 에이전트가 거부됩니다. 다시 켜면 같은 토큰을 그대로 씁니다.

스위치와 토큰은 데이터 폴더의 `mcp.json`에 저장되며 나만 읽을 수 있습니다. 백업에는 포함되지 않으므로, 백업을 복원해도 에이전트 접근이 켜지지 않습니다.
