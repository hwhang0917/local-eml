# 메일 가져오기

메일은 모두 **가져오기** 화면에서 넣습니다. 이미 있는 메일은 알아서 건너뛰기 때문에 같은 파일을 두 번 가져와도 괜찮습니다. 가져오는 중에 언제든 취소할 수 있습니다.

![가져오기 화면](https://hwhang0917.github.io/local-eml/img/ko/import.webp)

## 파일과 폴더

아래 파일을 화면에 끌어다 놓거나, 클릭해서 고르세요.

- `.eml` 파일 (한 개씩 또는 폴더째로)
- `.eml` 파일이 들어 있는 `.zip` 파일
- Google 테이크아웃, Thunderbird, Apple Mail에서 내보낸 `.mbox` 파일
- Outlook `.pst` 파일

어떤 형식으로 넣든, 메일은 한 통마다 `.eml` 파일 하나로 라이브러리에 저장됩니다.

## IMAP 메일함

IMAP은 메일 앱이 서버에 있는 메일함을 읽을 때 쓰는 표준 방식입니다. 서버 주소(호스트), 포트, 사용자 이름, 비밀번호, 폴더를 입력하세요. 대부분은 암호화(TLS)된 993 포트를 씁니다. 143 포트도 되며, 이때는 STARTTLS로 암호화합니다. 폴더는 따로 바꾸지 않으면 `INBOX`입니다.

Local Eml은 읽기만 합니다. 메일을 복사해 올 뿐, 서버에 있는 메일을 옮기거나 표시를 바꾸거나 지우지 않습니다.

접속 정보는 **프로필**로 저장해 두면 다음에 다시 입력하지 않아도 됩니다. 비밀번호는 저장하지 않으므로 매번 입력해야 합니다. 단, 그 프로필에서 백그라운드 동기화를 켜면 비밀번호도 저장됩니다. 자세한 내용은 [새 메일 받기](./sync)를 참고하세요.

## AWS S3 버킷

버킷, 리전, 키 접두어(선택), 액세스 키 ID, 시크릿 키를 입력하세요. 시크릿 키와 세션 토큰은 저장하지 않으므로 매번 입력해야 합니다. 나머지는 프로필로 저장할 수 있습니다.

## 내보내기

**내보내기** 화면에서 라이브러리 전체를 `.zip` 파일 하나로 저장하거나 S3 버킷에 올릴 수 있습니다. 버킷에 이미 있는 파일은 건너뛰기 때문에 같은 내보내기를 다시 실행해도 문제없습니다.

`.zip` 안에는 데이터베이스 사본도 들어 있습니다. 저장된 비밀번호는 빠져 있습니다. 새 컴퓨터 등에서 그 안의 `.eml` 파일을 가져온 다음 **설정 → 백업 복원**을 쓰면 별표, 분류, 설정, 프로필이 되살아납니다.

## 자동 백업

보관한 뒤 메일함에서 메일을 지웠다면, 그 메일은 Local Eml에만 남아 있을 수 있습니다. **내보내기** 화면 아래쪽의 **자동 백업**은 정해진 주기마다 라이브러리를 폴더에 복사해서, 디스크 하나가 고장 나도 메일을 잃지 않게 합니다.

1. 외장 드라이브, NAS, 또는 Dropbox·OneDrive·Google Drive가 동기화하는 폴더의 전체 경로를 입력합니다. 예: `E:\메일 백업`, `/Volumes/Backup/Mail`. 폴더가 없으면 새로 만듭니다.
2. **매일** 또는 **매주**를 고르고 **저장**을 누릅니다. **지금 백업**을 누르면 바로 한 번 실행합니다.

백업은 Local Eml이 실행 중일 때 돌아갑니다. 백그라운드 서비스로 설치했다면 항상, 아니면 창이 열려 있는 동안입니다. 꺼져 있는 동안 놓친 백업은 다음에 켜고 2분쯤 뒤에 실행됩니다. 첫 백업은 모든 메일을 복사하고, 그다음부터는 새 메일만 복사하므로 보통 몇 초면 끝납니다. 백업 폴더에서는 아무것도 지우지 않으므로 Local Eml에서 지운 메일도 백업에는 남습니다. 드라이브가 연결되지 않은 경우처럼 백업이 실패하면 이유와 마지막으로 성공한 백업 시각을 보여 주고, 한 시간 뒤 다시 시도합니다.

폴더에는 메일마다 `.eml` 파일 하나씩 들어 있는 `emails` 폴더와, 별표·분류·설정·프로필(비밀번호 제외)이 담긴 `local-eml.db`가 있습니다. 새 컴퓨터에서 되살리려면 `emails` 폴더를 **가져오기** 화면에 놓은 다음, **설정 → 백업 복원**에서 `local-eml.db`를 고르세요.
