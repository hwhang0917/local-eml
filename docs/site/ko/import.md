# 메일 가져오기

모든 메일은 **가져오기** 페이지를 통해 들어옵니다. 파일 해시로 중복을 걸러내므로 같은 소스를 두 번 가져와도 문제없습니다. 진행 중인 가져오기는 언제든 취소할 수 있습니다.

![가져오기 페이지](https://hwhang0917.github.io/local-eml/img/ko/import.webp)

## 파일과 폴더

다음을 페이지에 끌어다 놓거나 파일 선택기로 고르세요.

- `.eml` 파일 하나 또는 `.eml`이 담긴 폴더
- `.eml` 파일이 들어 있는 `.zip` 압축 파일
- Google 테이크아웃, Thunderbird, Apple Mail이 내보내는 `.mbox` 파일
- Outlook `.pst` 파일

어떤 형식으로 들어왔든 메일 한 통은 라이브러리에 `.eml` 파일 하나가 됩니다.

## IMAP 메일함

호스트, 포트, 사용자명, 비밀번호, 폴더를 입력합니다. 993 포트는 TLS로, 143 포트는 STARTTLS로 연결합니다. 폴더 기본값은 `INBOX`입니다.

접근은 읽기 전용입니다. Local Eml은 복사본만 가져오며 서버의 메일을 옮기거나 표시하거나 지우지 않습니다.

접속 정보를 **프로필**로 저장하면 다시 입력할 필요가 없습니다. 비밀번호는 기본적으로 저장하지 않고 매번 입력합니다. 프로필의 백그라운드 동기화를 켤 때만 저장되며, 자세한 내용은 [새 메일 받기](./sync)를 보세요.

## AWS S3 버킷

버킷, 리전, 선택 사항인 키 접두어, Access Key ID, Secret Key를 입력합니다. Secret Key와 세션 토큰은 저장하지 않고 가져올 때마다 입력합니다. 나머지는 프로필로 저장할 수 있습니다.

## 내보내기

**내보내기** 페이지에서 라이브러리 전체를 `.zip` 하나로 내려받거나 S3 버킷에 올릴 수 있습니다. 대상에 이미 있는 키는 건너뛰므로 여러 번 실행해도 안전합니다.

`.zip`에는 저장된 비밀번호를 제외한 데이터베이스 스냅샷이 들어 있습니다. `.eml` 파일을 가져온 뒤 **설정 → 백업에서 복원**으로 별표, 카테고리, 설정, 프로필을 되살릴 수 있습니다.
