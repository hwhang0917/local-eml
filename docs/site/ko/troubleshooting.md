# 문제 해결

## 서버가 응답하지 않는다는 빨간 배너가 떠요

화면은 열려 있지만 뒤에서 돌아가는 프로그램이 멈춘 상태입니다. 백그라운드 서비스로 설치했다면 다시 시작하세요.

```bash
# Linux
systemctl --user restart local-eml
# macOS
launchctl kickstart -k gui/$(id -u)/local-eml
```

Windows에서는 **서비스** 앱을 열어 **Local Eml**을 찾아 다시 시작하세요. 더블클릭으로 쓰고 있다면 프로그램을 다시 열면 됩니다.

## "창을 더 넓혀 주세요"라고 나와요

창이 너무 좁아서 그렇습니다. 창을 넓히거나 최대화하세요. 인쇄할 때 이 화면이 나온다면 v0.15.1 이상으로 업데이트하세요. 그 버전에서 고쳐졌습니다.

## 7878 포트를 이미 다른 프로그램이 쓰고 있어요

다른 포트로 다시 설치하세요. 설치 스크립트를 실행하기 전에 `LOCAL_EML_PORT`를 지정하면 됩니다([설치](./install#백그라운드-서비스-linux-macos-windows) 참고). 서버를 직접 실행한다면 `local-eml serve --port 9000`처럼 쓰세요.

## 더블클릭하면 새 창 대신 서비스 화면이 열려요

일부러 그렇게 만들었습니다. 백그라운드 서비스가 실행 중이면 프로그램을 하나 더 띄우지 않고 서비스 화면을 엽니다. 서비스의 라이브러리와 섞이지 않는 별도 세션이 필요하면 [임시 세션](./privacy#임시-세션)을 쓰세요.

## 업데이트하려니 winget을 쓰라고 나와요

winget으로 설치했기 때문에 업데이트도 winget이 관리합니다. 다음 명령을 실행하세요.

```powershell
winget upgrade hwhang0917.LocalEml
```

## 정상 메일인데 피싱 경고가 떠요

자동 검사라서 틀릴 때도 있습니다. 배너에서 **스팸 아님**을 고르면 그 메일의 경고가 사라집니다. 경고를 아예 끄려면 **설정 → 스팸·피싱**으로 가세요. 자세한 내용은 [스팸과 피싱](./spam-phishing)을 참고하세요.

## 새 메일 알림이 안 와요

먼저 동기화 설정 아래의 **새 메일이 오면 알림 받기**가 체크되어 있고, Local Eml이 브라우저 탭에 열려 있는지 확인하세요. HTTPS가 아니어도 괜찮습니다. 브라우저는 `http://localhost`를 안전한 주소로 취급하므로 `http://localhost:7878`에서도 알림이 동작합니다.

옵션은 켜져 있는데 아무것도 뜨지 않는다면, 대부분 운영체제 설정이 알림을 막고 있는 것입니다. 앱에서 옵션 옆의 **(?)** 를 누르면 같은 안내가 나오고, **테스트 알림 보내기**로 설정이 맞는지 바로 확인할 수 있습니다. 알림은 브라우저가 띄우기 때문에 설정은 Local Eml이 아니라 브라우저 이름(Google Chrome, Microsoft Edge, Safari, Firefox) 아래에 있습니다.

**Windows**

1. **설정 → 시스템 → 알림**에서 **방해 금지 모드**를 끄세요.
2. 같은 화면에서 **자동으로 방해 금지 모드 켜기**를 열고 *디스플레이를 복제할 때*, *게임할 때*, *앱을 전체 화면 모드로 사용할 때*처럼 원하지 않는 규칙을 해제하세요.
3. **앱 및 다른 보낸 사람의 알림**에서 사용하는 브라우저를 누르고 **알림 배너 표시**를 켜세요. 알림 목록(Windows 키 + N)에는 쌓이는데 오른쪽 아래에 팝업이 뜨지 않는다면 대부분 이 설정 때문입니다.

**macOS**

1. **시스템 설정 → 알림**에서 사용하는 브라우저를 고르고 **알림 허용**을 켜세요. Chrome은 *Google Chrome Helper (Alerts)*로 보일 수도 있습니다.
2. 같은 화면에서 알림 스타일을 **배너**나 **알림**으로 고르세요. **없음**이면 알림 센터에만 쌓입니다.
3. 메뉴 막대에 집중 모드 아이콘(달 모양)이 보이면 알림이 보류됩니다. 제어 센터에서 집중 모드를 끄거나, **시스템 설정 → 집중 모드**에서 브라우저를 허용된 앱에 추가하세요.

Linux에서는 데스크톱 환경의 방해 금지 설정과 브라우저 알림 설정을 확인하세요.

## 로그 파일은 어디 있나요

Linux와 macOS:

```bash
tail -f ~/.local-eml/logs/local-eml.log
```

Windows에서는 `%USERPROFILE%\.local-eml\logs\local-eml.log`입니다. 더 자세한 로그가 필요하면 서비스 환경 변수에 `LOCAL_EML_LOG_LEVEL=debug`를 넣으세요. 로그에는 메일 제목과 주소가 들어 있으니, 다른 사람에게 보여 주기 전에 개인 정보는 지워 주세요.
