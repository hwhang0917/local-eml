# Browsing attachments

The **Attachments** page lists every file attached to every message in one table, so you can find a file without remembering which email it came in. It is also a quick way to see what is taking up space.

Inline images, such as logos in an email's signature, are not attachments and aren't listed. Neither are attachments of messages marked as spam or phishing.

![The attachments page](https://hwhang0917.github.io/local-eml/img/en/attachments.webp)

## Finding a file

- **Search file names** matches any part of a file name. `invoice` finds `INV-invoice-2291.pdf` and `invoice_march.xlsx`.
- **Filter by sender** matches any part of the sender's name or address.
- **File type** narrows the list to images, PDFs, documents, spreadsheets, archives, audio and video, or everything else. Each choice shows how many files it holds. The type comes from the file's declared format, or from its extension when the sender didn't declare one.
- **Date range** uses the date the email was sent.

Click a column heading to sort by name, type, size, date or sender. Sorting by size, largest first, shows what takes up the most space. The total count and size of the files that match are shown next to the page title.

## Opening a file

Each row has up to three buttons:

- **Open in a new tab** shows images, PDFs, audio, video and plain text in your browser. Other files can't be opened safely in the browser, so they only have a download button.
- **Download** saves the file.
- **Go to the email** opens the message the file came in, on its **Attachments** tab. For a file that can be previewed, the preview is already open.

Clicking the file name does the same as **Open in a new tab**, or downloads the file when it can't be opened.

## After updating

The list is built when mail is imported. Mail imported with an older version of Local Eml is added in the background the first time the new version starts. On a large library they may take a moment to appear.
