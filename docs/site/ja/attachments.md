# 添付ファイルを探す

**添付ファイル**ページには、すべてのメールに添付されたファイルが1つの表にまとめて表示されます。どのメールに付いていたかを覚えていなくても、ファイルを見つけられます。何が容量を使っているのかを手早く確認するのにも便利です。

メールの署名に入っているロゴのようなインライン画像は添付ファイルではないため、一覧には表示されません。迷惑メールまたはフィッシングとしてマークしたメールの添付ファイルも表示されません。

## ファイルを探す

- **ファイル名を検索**：ファイル名の一部に一致します。`invoice`で`INV-invoice-2291.pdf`や`invoice_march.xlsx`が見つかります。
- **差出人で絞り込む**：差出人の名前またはアドレスの一部に一致します。
- **ファイルの種類**：画像、PDF、文書、スプレッドシート、アーカイブ、音声・動画、その他のいずれかに絞り込みます。それぞれの選択肢に、該当するファイルの数が表示されます。種類はファイルに宣言されている形式から判断し、差出人が宣言していない場合は拡張子から判断します。
- **期間**：メールが送信された日付を使います。

列の見出しをクリックすると、名前、種類、サイズ、日付、差出人で並べ替えられます。サイズの大きい順に並べると、何がいちばん容量を使っているかがわかります。条件に一致するファイルの総数と合計サイズは、ページタイトルの横に表示されます。

## ファイルを開く

各行には最大3つのボタンがあります。

- **新しいタブで開く**：画像、PDF、音声、動画、プレーンテキストをブラウザで表示します。それ以外のファイルはブラウザで安全に開けないため、ダウンロードボタンだけが表示されます。
- **ダウンロード**：ファイルを保存します。
- **メールに移動**：そのファイルが付いていたメールを、**添付ファイル**タブで開きます。プレビューできるファイルの場合は、プレビューが開いた状態で表示されます。Hangul、Word、Excelのファイルは、名前をクリックしたときも、ダウンロードせずにここへ移動します。

ファイル名をクリックすると、**新しいタブで開く**と同じ動作になります。開けないファイルの場合はダウンロードされます。

## アップデート後

一覧はメールをインポートするときに作成されます。古いバージョンのLocal Emlでインポートしたメールは、新しいバージョンを初めて起動したときにバックグラウンドで追加されます。ライブラリが大きい場合、表示されるまで少し時間がかかることがあります。
