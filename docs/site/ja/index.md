features:
  - title: 送るためではなく、保管するための道具
    details: メールは通常の.emlファイルとして保存されます。送信や返信はできず、メールボックスの内容が変更されることもありません。
  - title: 自分のコンピューターの中だけで
    details: 1つのプログラムだけで動き、接続できるのは自分のコンピューターだけです。データはすべて1つのフォルダに入っています。
  - title: 日本語もそのまま検索
    details: 差出人、件名、本文、添付ファイル名をまとめて検索でき、`from:`や`has:attachment`などのフィルターも使えます。ハングルの初声検索（초성검색）にも対応しています。
  - title: 新着メールは届いたらすぐに
    details: IMAPプロファイルでバックグラウンド同期をオンにすると、対応しているサーバーでは新着メールが数秒で届きます。デスクトップ通知も受け取れます。
  - title: 添付ファイルを一か所で
    details: すべてのメールの添付ファイルを種類、差出人、日付で探し、統計ページで何が容量を使っているかを確認できます。
  - title: バックアップとエクスポート
    details: 毎日または毎週、新しいメールをバックアップ用フォルダにコピーできます。検索結果だけを.emlファイル、.mbox、PDFとしてエクスポートすることもできます。
  - title: ハングル・Officeの文書をプレビュー
    details: ハングル（HWP、HWPX）、Word、Excelの添付ファイルを、ほかのソフトなしでアプリ内で開けます。
  - title: どのS3ストレージでも
    details: AWS S3はもちろん、MinIO、Cloudflare R2、Backblaze B2などのS3互換ストレージから取り込み、エクスポートできます。
