# Outlookなしで.pstファイルを開く方法

`.pst`ファイルはOutlookのメールボックスを1つのファイルとして保存したものです。通常、開くにはOutlookがインストールされている必要があります。Local Emlは`.pst`ファイルを自分で読めるので、MacやLinuxを含むどのコンピューターでも、古いアーカイブの中身を確認できます。

## .pstファイルの出どころ

- Outlookからのエクスポート：**ファイル → 開く/エクスポート → インポート/エクスポート → ファイルにエクスポート → Outlook データ ファイル (.pst)**。
- Outlookの古いアイテムの整理（自動整理）機能。通常は`ドキュメント\Outlook ファイル`に保存されます。
- IT部門や以前の勤務先から受け取った、自分のメールボックスのコピー。

## Local Emlで開く

1. Local Emlを開き、**インポート**に移動します。
2. `.pst`ファイルをページにドラッグするか、クリックして選択します。
3. インポートが終わるまで待ちます。すべてのメールが添付ファイルごと`.eml`ファイルとしてライブラリに保存されます。

`.pst`の中のフォルダ構成は保持されません。すべてのメールが1つの一覧に表示されるので、検索、日付、差出人で探します。カテゴリを使って自分で分類することもできます。

## 対応していないもの

- **`.ost`ファイル。** これはアーカイブではなく使用中のメールボックスをOutlookが一時的にコピーしたもので、Local Emlでは読めません。代わりに、Outlookから`.pst`をエクスポートしてください。
- **IMAP経由のOutlook.comアカウント。** Microsoftは、アプリがパスワードでOutlook.comのメールボックスにサインインすることを認めなくなったため、Local EmlのIMAPインポートでは接続できません。代わりに、デスクトップ版のOutlookアプリから`.pst`をエクスポートしてください。

`.pst`をインポートできない場合は、インポート時のエラーメッセージを添えて[issueを作成](https://github.com/hwhang0917/local-eml/issues)してください。ファイルにはあなたのメールが入っているので、ファイルそのものは添付しないでください。
