# Google データエクスポートの.mboxファイルを見る方法

Google データエクスポート（Google Takeout）は、Gmailを1つ以上の`.mbox`ファイルとして書き出します。ほとんどのメールアプリはこれを直接開けません。Local Emlはこのファイルをインポートし、メールを1通ずつ検索可能な`.eml`ファイルに変換します。

## 1. Google データエクスポートで書き出す

1. [takeout.google.com](https://takeout.google.com)を開きます。
2. **選択をすべて解除**をクリックしてから、**メール**にチェックを入れます。一部のラベルだけが必要な場合は、**メールのすべてのデータが含まれます**をクリックして選びます。
3. エクスポートの受け取り方法とファイルサイズを選び、**エクスポートを作成**をクリックします。準備ができるとGoogleからメールが届きます。メールボックスが大きい場合は、数時間から数日かかることがあります。
4. アーカイブをダウンロードして展開します。中の`Mail`フォルダに、1つ以上の`.mbox`ファイルが入っています。通常は`すべてのメール（迷惑メール、ゴミ箱のメールを含む）.mbox`のように、ラベルにちなんだ名前が付いています。

## 2. Local Emlにインポートする

1. Local Emlを開き、**インポート**に移動します。
2. `.mbox`ファイルをページにドラッグします。Local Emlはデータエクスポートのzipに入ったままの`.mbox`を読めないので、必ず先にアーカイブを展開してください。
3. 完了するまで待ちます。データエクスポートのファイル同士に重なりがあっても、各メールがインポートされるのは1回だけです。いつでもキャンセルできます。

大きなエクスポートのインポートには時間がかかりますが、終わってしまえば、メールが10万通を超えていても閲覧と検索は高速です。

## 3. 確認して検索する

**ライブラリ**を開きます。メールには、元の日付、差出人、添付ファイルがそのまま残っています。期間のフィルターで特定の時期を探したり、差出人、件名、本文で検索したりできます。

## 新着メールも受信する

データエクスポートは1回限りのコピーです。Gmailの新着メールも引き続き受信したい場合は、IMAPでもGmailに接続してください。方法は[Gmailの容量を空ける](./free-up-gmail)で説明しています。両方を併用できます。すでにライブラリにあるメールはスキップされます。
