# メールを失わずにGmailの容量を空ける方法

Gmailの保存容量はGoogle ドライブやGoogle フォトと共有されており、古いメールがその多くを占めていることがよくあります。Local Emlを使えば、そうしたメールの検索可能な完全なコピーを自分のコンピューターに保管したうえで、Gmailから削除できます。

Local EmlがGmailから何かを削除することはありません。コピーをダウンロードするだけです。Gmailで何を削除するかは、コピーが揃っていることを確認したうえで、自分で決めます。

## 方法A：IMAPで接続する

Gmailから直接ダウンロードする方法で、あとから新着メールを受信し続けることもできます。

1. **アプリ パスワードを作成します。** Gmailはほかのアプリからの通常のパスワードを受け付けません。Googleアカウントで2段階認証プロセスがまだオンになっていなければ、オンにします。次に[myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)を開き、「Local Eml」という名前でパスワードを作成して、表示された16文字をコピーします。
2. Local Emlで**インポート**に移動し、**IMAP**を選びます。
3. ホストに`imap.gmail.com`、ポートに`993`、ユーザー名にGmailのアドレスを入力し、アプリ パスワードを入力します。
4. すべてのメールを取得するには、フォルダを`[Gmail]/All Mail`にします。この名前はGmailの表示言語によって変わり、日本語では`[Gmail]/すべてのメール`です。受信トレイだけを取得する場合は、`INBOX`のままにします。
5. プロファイルとして保存し、インポートを開始します。大きなアカウントでは時間がかかります。途中で止めてあとで再開することもでき、同じものが2回ダウンロードされることはありません。

新着メールを受信し続けたい場合は、そのプロファイルでバックグラウンド同期をオンにしてください。[新着メールの受信](../sync)を参照してください。

## 方法B：Google データエクスポート

アプリ パスワードを作成したくない場合は、Google データエクスポートでメールを書き出し、`.mbox`ファイルをインポートします。これは1回限りのコピーです。[Google データエクスポートの.mboxを見る](./takeout-mbox)を参照してください。

## コピーを確認してからGmailで削除する

1. Local Emlで**統計**を開き、メールが何通あるか、どの期間のものかを確認します。
2. 添付ファイル付きのものも含めて古いメールをいくつか開き、正しく表示されることを確かめます。
3. Gmailで、コピーしたメールを検索します。たとえば、5年より古いメールなら`older_than:5y`です。すべて選択して削除します。そのあとゴミ箱を空にしてください。Gmailは削除したメールをゴミ箱に30日間残すので、空にするまで容量は戻りません。

Local Emlのライブラリもほかの大切なフォルダと同じようにバックアップしてください。**エクスポート**を使うと、どこにでも保管できる1つの`.zip`として保存できます。
