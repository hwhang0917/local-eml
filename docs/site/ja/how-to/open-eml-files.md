# WindowsやMacで.emlファイルを開く方法

`.eml`ファイルは1通のメールを本文と添付ファイルごと1つのファイルとして保存したものです。メールアプリからメールを保存したとき、誰かがメールを添付ファイルとして転送してきたとき、バックアップツールがメールボックスを1通ずつ書き出したときなどに、手元に残ります。

メールアプリを設定してあれば、WindowsやmacOSは1つの`.eml`ファイルをそのアプリで開けます。フォルダいっぱいのファイルがある場合や、メールアカウントに追加したくない場合は、Local Emlのようなビューアのほうが簡単です。

## Local Emlで.emlファイルを開く

1. [最新リリース](https://github.com/hwhang0917/local-eml/releases/latest)からお使いのシステム用のLocal Emlをダウンロードして開きます。初回にWindowsやmacOSが警告を表示した場合の対処は、[インストール](../install)で説明しています。
2. ブラウザのウィンドウが**インポート**ページで開きます。`.eml`ファイル、またはファイルの入ったフォルダをそこにドラッグします。`.eml`ファイルをまとめた`.zip`でもかまいません。
3. **ライブラリ**ページに移動します。すべてのメールが差出人と件名とともに日付順で一覧表示されます。クリックすると読めます。

添付ファイルはメールの下に一覧表示され、画像、PDF、音声、動画、Hangul（HWP、HWPX）、Word（DOCX）、Excel（XLSX、XLS）のファイルはプレビューできます。プレビューはアプリの中で描画されるので、文書がコンピューターの外に出ることはありません。インターネット上に置かれた画像は、クリックして読み込まない限り読み込まれないので、メールを開いたことが差出人に伝わりません。

## フォルダ内の.emlファイルを検索する

検索ボックスに入力すると、インポートしたすべてのメールの差出人、件名、本文を検索できます。日本語のテキストもそのまま検索できます。[検索](../search)を参照してください。

## 保管するか何も残さないか

インポートすると、メールはLocal Emlのフォルダにコピーされます。元のファイルは変更されません。見るだけで何も残したくない場合は、先に[一時セッション](../privacy#temporary-sessions)をオンにしてください。

## ほかの形式

Local Emlは、[Google データエクスポート](./takeout-mbox)、Thunderbird、Apple Mailの`.mbox`ファイルや、Outlookの[`.pst`ファイル](./pst-without-outlook)も開けます。
