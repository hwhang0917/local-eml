# トラブルシューティング

## サーバーが応答していないという赤いバナーが表示される

ページは開いたままですが、その裏で動くプログラムが停止しています。バックグラウンドサービスをインストールした場合は、再起動してください。

```bash
# Linux
systemctl --user restart local-eml
# macOS
launchctl kickstart -k gui/$(id -u)/local-eml
```

Windowsでは**サービス**を開いて**Local Eml**を探し、再起動します。ダブルクリックで使っている場合は、プログラムをもう一度開くだけです。

## 「ウィンドウの幅を広げてください」と表示される

ウィンドウが狭すぎます。幅を広げるか、最大化してください。印刷するときにこの表示が出る場合は、修正済みのv0.15.1以降にアップデートしてください。

## ポート7878がすでに使われている

Local Emlは自動的に次の空きポート（7879、次に7880…）へ移り、どのポートを選んだかをログに記録します。プログラムをダブルクリックすれば、移った先のポートでも見つけられます。別のLocal Emlがすでにそのポートを使っている場合、2つ目は起動しません。

決まったアドレスを使い続けたい場合は、インストールスクリプトを実行する前に`LOCAL_EML_PORT`を設定し、別のポートでインストールし直してください（[インストール](./install#background-service)を参照）。自分でサーバーを起動する場合は、`local-eml serve --port 9000`を使います。この方法で選んだポートが変更されることはありません。使われていた場合、サーバーはエラーで停止します。

## ダブルクリックするとサービスが開く

これは意図した動作です。バックグラウンドサービスが動いている場合、ダブルクリックしても2つ目のプログラムは起動せず、サービスの画面を表示するウィンドウが開きます。サービスのライブラリに触れない別のセッションが必要な場合は、[一時セッション](./privacy#temporary-sessions)を使ってください。

## アップデート機能に「wingetを使ってください」と表示される

このプログラムはwingetでインストールされているため、アップデートはwingetが行います。次のコマンドを実行してください。

```powershell
winget upgrade hwhang0917.LocalEml
```

## 普通のメールにフィッシングの警告が表示される

この確認が毎回正しいとは限りません。バナーで**迷惑メールではない**を選んでそのメールの警告を非表示にするか、**設定 → 迷惑メール・フィッシング**で警告をオフにしてください。[迷惑メールとフィッシング](./spam-phishing)を参照してください。

## 新着メールの通知が表示されない {#notifications}

まず、同期の設定で**新着メールが届いたら通知する**がオンになっていること、Local Emlをブラウザのタブで開いていることを確認してください。通知のためにサイトをHTTPSにする必要はありません。ブラウザは`http://localhost`を安全なものとして扱うので、`http://localhost:7878`でも通知は動作します。

オプションはオンなのに何も表示されない場合、たいていはOSが通知を止めています。オプションの横にある（**?**）をクリックすると、アプリ内でこの手順を確認でき、そこにある**テスト通知を送る**で設定を確かめられます。通知を表示するのはブラウザなので、設定はLocal Emlではなくブラウザの名前（Google Chrome、Microsoft Edge、Safari、Firefox）の下にあります。

**Windows**

1. **設定 → システム → 通知**を開き、**応答不可**をオフにします。
2. 同じ画面で**応答不可を自動的にオンにする**を開き、*ディスプレイを複製しているとき*、*ゲームをプレイしているとき*、*アプリを全画面モードで使用しているとき*など、不要なルールのチェックを外します。
3. **アプリやその他の送信者からの通知**でお使いのブラウザをクリックし、**通知バナーを表示する**をオンにします。通知が一覧（Windowsキー + N）には入るのに画面の隅にポップアップしない場合、たいていはこれが原因です。

**macOS**

1. **システム設定 → 通知**を開き、お使いのブラウザを選んで**通知を許可**をオンにします。Chromeは*Google Chrome Helper (Alerts)*と表示されることがあります。
2. 同じ画面で、通知スタイルを**バナー**または**通知パネル**にします。**なし**にすると、通知は通知センターにたまるだけになります。
3. メニューバーに集中モードのアイコン（月のマーク）がある場合、通知は保留されています。コントロールセンターで集中モードをオフにするか、**システム設定 → 集中モード**で許可するアプリにブラウザを追加してください。

Linuxではデスクトップ環境の「通知を表示しない」設定と、ブラウザに対する通知設定を確認してください。

## ログファイルの場所

LinuxとmacOSでは次のコマンドで確認できます。

```bash
tail -F ~/.local-eml/logs/local-eml.log
```

`-F`を付けると、日付が変わってログが切り替わったあとも追い続けます。過去の日付のログは同じ場所の`local-eml-YYYY-MM-DD.log`に30日間保管されます。Windowsでは、ファイルは`%USERPROFILE%\.local-eml\logs\local-eml.log`です。より詳しい情報が必要な場合は、サービスの環境変数に`LOCAL_EML_LOG_LEVEL=debug`を設定してください。ログには件名とメールアドレスが含まれるので、共有する前に個人的な情報を取り除いてください。
