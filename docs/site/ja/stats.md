# ライブラリの統計

**統計**ページでは、ライブラリの中身を一目で確認できます。メールがどれだけあり、誰から届き、いつ届くのか、何が容量を使っているのかがわかります。何を残すか決めるときや、大量にインポートしたあとで期待どおりに取り込まれたか確かめるときに役立ちます。

![統計ページ](https://hwhang0917.github.io/local-eml/img/ja/stats.webp)

ページ上の項目のほとんどはリンクになっています。差出人、ドメイン、カテゴリ、受信トレイの状態の数字をクリックすると、その条件で絞り込んだライブラリが開きます。

## ページの内容

- 上部の**合計**：メール数、合計サイズ、スター付きのメール数、添付ファイルがあるメール数
- **メール数の推移**：月ごとに何通届いたかを表示します。**年別**に切り替えると大きな流れがわかります。グラフにマウスを合わせると正確な数が表示されます。
- **メールが届く時間帯**：曜日と時間帯のマス目です。自分のコンピューターのタイムゾーンが基準で、色が濃いほどその時間に多くのメールが届いています。仕事の時間帯が多いのか、夜遅くが多いのかがすぐにわかります。最も多い時間帯は下に表示されます。
- **上位の差出人**：メールを多く送ってきた人の順です。**ドメイン**に切り替えると、`example.com`のように会社やメールサービスごとにまとめて表示します。
- **受信トレイの状態**：未読、スター付き、カテゴリなしのメール、迷惑メール・フィッシングとしてマークしたメール、フィッシングの警告が出ているメールの数です。未読は[既読管理](./settings-cli#settings)がオンの場合にだけ表示されます。
- **容量の内訳**：ライブラリのサイズを、本文と添付ファイルの種類（PDF、画像、音声・動画など）ごとに分けて表示します。種類をクリックすると、その種類のサイズの大きいファイルから順に[添付ファイル](./attachments)ページに表示されます。
- **サイズの大きいメール**：最も大きいメール5通です。クリックするとそのメールが開きます。
- **カテゴリ別**：色分けカテゴリごとのメール数です。

## アプリのリソース

一番下の**アプリのリソース**には、Local Eml自体の状態が表示され、ページを開いている間は3秒ごとに更新されます。メモリとCPUの使用量、ディスク上でライブラリが使っている容量（メールのファイル、データベースと検索インデックス、ログ）、そしてそのドライブの空き容量がわかります。最後の行には、起動してからの時間とバージョンが表示されます。バックグラウンドサービスを動かし続けている場合に、必要以上にリソースを使っていないか確かめるのに便利です。

日付のないメールは、グラフやマス目に配置できません。そうしたメールがある場合は、上部に何通あるかが表示されます。
