# 検索と閲覧

いちばん長く使うことになるのは**ライブラリ**ページです。メールの一覧が表示され、上部に検索ボックスとフィルターがあります。メールをクリックすると内容を読めます。

![ライブラリ](https://hwhang0917.github.io/local-eml/img/en/library.webp)

## 検索

検索ボックスはすべてのメールの差出人、宛先、件名、本文、添付ファイル名を対象に検索します。日本語、韓国語、中国語のテキストも、設定なしでそのまま検索できます。複数の語句を入力した場合は、そのすべてを含むメールだけが見つかります。語句がどの項目にあってもかまいません。

### ハングルの初声検索（초성검색）

韓国語は各音節の最初の子音（初声）だけを入力しても検索できます。`ㅎㄱ`で`한국`が、`ㅇㅁ`で`이메일`が見つかります。ライブラリ全体で使えます。

![検索結果](https://hwhang0917.github.io/local-eml/img/en/search.webp)

### 検索フィルター

検索ボックスにフィルターを加えると、結果を絞り込めます。たとえば、2019年にAmazonから届いた、PDF付きの領収書を探しているなら、次のように入力します。

```
領収書 from:amazon filename:pdf after:2019 before:2020
```

検索ボックスの右にあるスライダーのボタンをクリックすると、フィルターの一覧が表示されます。一覧のフィルターをクリックすると、検索に追加されます。

| フィルター | 見つかるメール |
|---|---|
| `from:alice` | 差出人の名前またはアドレスに`alice`を含むメール |
| `to:bob@example.com` | その人に宛てたメール（Ccを含む） |
| `cc:bob` | その人がCcに入っているメール |
| `subject:請求書` | 件名にその語句を含むメール |
| `filename:pdf` | ファイル名に`pdf`を含む添付ファイルがあるメール |
| `has:attachment` | 添付ファイルがあるメール |
| `is:starred` | スターを付けたメール |
| `is:unread` / `is:read` | まだ開いていない / 開いたことがあるメール（[既読管理](./settings-cli#settings)をオンにする必要があります） |
| `category:red` | そのカテゴリのメール。色、または自分で付けた名前を使います。`category:none`はカテゴリのないメールです |
| `after:2019-03` | その日以降に送信されたメール（当日を含む） |
| `before:2020` | その日より前に送信されたメール |
| `on:2024-05-17` | その日、その月、またはその年に送信されたメール |
| `until:2024-05-31` | その日までに送信されたメール（当日を含む） |
| `larger:5M` / `smaller:100K` | そのサイズより大きい / 小さいメール（K、M、G） |
| `"完全一致のフレーズ"` | それらの語句がその順序で隣り合っているメール |
| `-語句` | その語句を**含まない**メール。フィルターにも使えます：`-from:newsletter`、`-has:attachment` |

日付は年（`2019`）、月（`2019-03`）、日（`2019-03-05`）で指定できるので、`after:2019 before:2020`は2019年全体になります。日付は、期間の指定と同じく、お使いのコンピューターのタイムゾーンで解釈されます。フィルターはボタンや期間の指定と組み合わせて使えます。その場合はすべての条件に一致するメールだけが表示されます。

`from:`のあとに何も入力していない場合など、つづりが間違っていたり入力の途中だったりするフィルターは無視されます。結果が空になることはありません。

## フィルター

検索ボックスの横にあるボタンは検索フィルターのショートカットです。クリックすると対応するフィルターが検索ボックスに書き込まれます。現在の絞り込み条件は常に検索ボックスにすべて表示され、そこで編集することもできます。

- **スター付き**：`is:starred`を追加します。もう一度クリックすると外れます。
- **未読**：`is:unread`を追加します。
- **期間**：選んだ日付で`after:`と`until:`を追加します。
- **カテゴリ**：色のセットです。**設定 → カテゴリ**で名前を付け、一覧やメールを読んでいる画面からメールに割り当てます。フィルターで選ぶと、`category:blue`のように色を使った`category:`が追加されるので、名前を変えてもフィルターはそのまま機能します。
- **リセット**：検索ボックスと並び順をクリアします。
- **スレッドでまとめる**：各スレッドを、最新のメールを使った1行として表示します。件数をクリックすると残りが表示されます。

## 保存した検索

同じ検索をよく実行するなら、保存しておきましょう。検索語を入力するか、使いたいフィルターをクリックしてから、**保存した検索**を開いて**この検索を保存**を選びます。`領収書 filename:pdf -from:newsletter`に「領収書」のような名前を付けます。

次回からは**保存した検索**を開いて名前をクリックするだけです。その検索が有効な間は、ボタンに名前が表示されます。すでに使っている名前で保存すると、その検索が置き換えられます。名前の横の×をクリックすると、確認のうえで削除されます。保存した検索は設定と一緒に保管されるので、バックアップにも含まれます。

## 検索結果のエクスポート {#exporting-search-results}

メールの一部をLocal Emlの外に取り出せます。たとえば、大家から届いたメールをすべて弁護士に送りたいときに使います。方法は2つあります。

- **結果N件をエクスポート**：検索している間、フィルターの横に表示されます。いま見ているページだけでなく、一致するすべてのメールをエクスポートします。
- **エクスポート**：メールを選択すると、ヘッダーに表示されます。選択したメールだけをエクスポートします。**スレッドでまとめる**がオンの場合、選択した行のスレッド全体がエクスポートされます。

どちらも3つの形式から選べます。

| 形式 | 得られるもの |
|---|---|
| **.emlファイルを.zipで** | メール1通につき1つの`.eml`ファイル（日付と件名で名前が付きます）と、ExcelやNumbersで開ける全体の一覧`index.csv`。 |
| **1つの.mboxファイル** | Thunderbird、Apple Mail、別のLocal Emlで開ける、すべてのメールを収めた1つのファイル。 |
| **印刷またはPDFとして保存** | すべてのメールを1つにまとめて印刷します。最初に目次があり、各メールは新しいページから始まります。印刷ダイアログで**PDF に保存**を選ぶと、1つのPDFになります。一度に印刷できるのは200件までです。 |

メールは古い順に出力されます。**エクスポート**ページの全体エクスポートとは違い、これらのファイルにデータベースは含まれないので、選んだメールだけが入ります。迷惑メールまたはフィッシングとしてマークしたメールは含まれません。

## 複数のメールを選択する

行の先頭にあるチェックボックスをオンにするか、ハイライトされているメールで`x`を押すと、メールを選択できます。ヘッダーのチェックボックスは現在のページのすべてを選択します。何かを選択すると、ヘッダーにできる操作が表示されます。

- **すべて既読にする**と**すべて未読にする**：既読管理がオンの場合に表示されます（[設定](./settings-cli#settings)を参照）。
- **すべて削除**：先に確認を求められます。メールとその`.eml`ファイルがコンピューターから削除され、元に戻せません。同じ取り込み元からもう一度インポートすると、また取り込まれます。

**スレッドでまとめる**がオンの場合、行を選択するとスレッド全体が選択され、操作はそのスレッドのすべてのメールに適用されます。

## メールを読む

HTMLメールは制限をかけたフレームの中に表示されるので、メール内のスクリプトは実行されません。インターネット上に置かれた画像は、クリックして読み込むまでブロックされます。これにより、メールを開いたことが差出人に伝わりません。リンクを開く前には、実際のリンク先が表示されます。

画像、PDF、音声、動画、テキスト、Hangul（HWP、HWPX）、Word（DOCX）、Excel（XLSX、XLS）の添付ファイルはプレビューできます。それ以外の添付ファイルはクリックするとダウンロードされます。

## 速度

メールが10万通を超えても、閲覧と検索は一瞬で終わります。唯一の例外は**スレッドでまとめる**で、非常に大きなライブラリでは1ページあたり1秒ほどかかることがあります。気になる場合はまとめ表示をオフにしてください。

| 操作 | 1万通 | 10万通 |
|---|---|---|
| 閲覧 / ページの切り替え | 1ms未満 | 1ms未満 |
| 一般的な語句の検索 | 1ms未満 | 約2ms |
| 初声検索 | 約5ms | 約50ms |
| `from:`や`has:attachment`などのフィルターを使った検索 | 1ms未満 | 約10ms |
| スレッドでまとめた表示 | 約85ms | 約0.9秒 |

添付ファイル名との照合も行うため、非常に大きなライブラリでは語句の検索に数ms余分にかかります。これらは一般的なノートPCで生成したテスト用メールを使い、総件数の集計を含めて50通分の1ページを読み込む時間を測定したものです。
