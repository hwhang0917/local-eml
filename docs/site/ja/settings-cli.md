# 設定とコマンドライン

## 設定 {#settings}

上部のメニューから**設定**を開きます。メニュー右端の本のアイコンをクリックすると、このドキュメントが新しいタブで開きます。

| ページ | できること |
|---|---|
| **このアプリについて** | バージョンを確認し、アップデートを確認します。バックグラウンドサービスとしてインストールした場合は、ここからアップデートできます。**ライブラリを再スキャン**は、データフォルダにあってもライブラリにまだ登録されていない`.eml`ファイルを追加します。このドキュメント、GitHub、問題の報告ページへのリンクもあります。 |
| **カテゴリ** | 色分けカテゴリに名前を付けます。 |
| **言語と地域** | 表示言語と、日付を「2024年3月3日」と「2年前」のどちらの形式で表示するかを選びます。 |
| **既読管理** | 既読管理をオンにします（既定ではオフ）。オンにすると、未読メールの件名が太字で表示され、メールを開くと既読になり、一覧に**未読**フィルターと各行の既読/未読ボタンが追加されます。初めてオンにするときに、既存のメールを既読と未読のどちらから始めるかを選びます。大量にインポートしたあとは、**すべて既読にする**でたまった未読を片付けられます。 |
| **バックアップから復元** | エクスポートした`.zip`から、スター、カテゴリ、設定、プロファイルを復元します。 |
| **重複メール** | 複数回保存されているメールを探し、それぞれ1つだけを残します。たとえば、データエクスポートの`.mbox`をインポートしたあと、同じアカウントをIMAPで同期した場合に起こります。スター、既読状態、カテゴリは引き継がれます。[重複メール](./import#duplicates)を参照してください。 |
| **迷惑メール・フィッシング** | マークしたメールを確認し、フィッシングの警告をオンまたはオフにします。 |
| **プライバシー** | 一時セッション、すべてのデータの削除、保存したIMAPパスワードの暗号鍵の保管場所。 |
| **オープンソースライセンス** | Local Emlが利用しているオープンソースライブラリのライセンス。 |

## コマンドライン

普段使うぶんには、コマンドラインは必要ありません。バックグラウンドサービスとスクリプトのために用意されています。

```text
local-eml <command> [flags]

  app [--ephemeral]        open in a browser window; stops when the window closes (default)
  serve [--port 7878] [--ephemeral]
                           run the local web server (loopback only)
  install [-y|--yes] [--port 7878]
                           start in the background at sign-in (systemd/launchd/Windows startup)
  uninstall [-y|--yes]     stop and unregister the background service
  token                    print the session token the API and a browser need
  version | -V | --version
```

コマンドを付けずにプログラムを実行すると、`app`と同じ動作になります。ダブルクリックしたときはこの動作になります。

`serve`を`--port`なしで実行したとき、ほかのプログラムがすでに7878を使っていると、次の空きポート（7897まで）に移り、どのポートを選んだかをログに記録します。別のポートを指定してインストールしていなければ、バックグラウンドサービスも同じ動作です。`--port`を指定した場合はそのポートだけを使い、使われていればエラーで停止します。[ポート7878がすでに使われている](./troubleshooting#port-7878)を参照してください。

`install`と`uninstall`は先に確認を求めます。スクリプトで確認を省くには`--yes`を付けます。

## セッショントークン {#session-token}

Local Emlに接続できるのは自分のコンピューターだけですが、そこにはコンピューター上のすべてのプログラムとすべてのユーザーアカウントが含まれます。そのため、サーバーはトークンも要求します。トークンはランダムなパスワードで、データフォルダの`session-token`というファイルに保存され、読めるのはあなただけです。

- ダブルクリックすると、自動的にサインインされます。プログラムがブラウザに渡すのは、トークンから作った1回限りのサインイン用リンクで、トークンそのものではありません。ブラウザは最後に使ってから30日間サインインしたままになります。
- 自分でブラウザにアドレスを入力して開いた場合は、初回にサインインページが表示されます。コマンド プロンプトまたはターミナルの開き方が示され、`local-eml token`コマンド用の**コピー**ボタンがあります。コマンドを実行し、表示されたトークンを貼り付けてください。
- スクリプトからはヘッダーで送ります：`curl -H "Authorization: Bearer $(local-eml token)" http://127.0.0.1:7878/api/stats`

[一時セッション](./privacy#temporary-sessions)には専用のトークンが発行され、ダブルクリックした場合は同じように自動で処理されます。

## 環境変数

| 変数 | 内容 |
|---|---|
| `LOCAL_EML_PORT` | インストールスクリプトが設定するポート。既定値は`7878`。 |
| `LOCAL_EML_SYNC_INTERVAL` | バックグラウンド同期が新着IMAPメールを確認する間隔。たとえば`5m`、または`off`。アプリ内で設定した値が優先されます。 |
| `LOCAL_EML_EPHEMERAL` | `1`にすると[一時セッション](./privacy#temporary-sessions)で起動します。バックグラウンドサービスでは無視されます。 |
| `LOCAL_EML_KEYRING` | `off`にすると、IMAPパスワードの暗号鍵をシステムの安全な保管場所ではなくファイルに置きます。すでに保管場所にある場合はファイルに戻します。[パスワードの扱い](./sync#what-happens-to-your-password)を参照してください。 |
| `LOCAL_EML_LOG_LEVEL` | `debug`、`info`、`warn`、`error`のいずれか。既定値は`info`。 |

バックグラウンドサービスの場合は、サービス自体の設定に指定します。Linuxではsystemdのユニット、macOSではLaunchAgentのplist、Windowsではサービスの設定です。

## デスクトップ専用

ウィンドウにはおよそ768ピクセル以上の幅が必要です。それより狭いと、幅を広げるよう求めるメッセージが表示されます。Local Emlに到達できるのは自分のコンピューターだけなので、スマートフォンからはそもそも接続できません。
