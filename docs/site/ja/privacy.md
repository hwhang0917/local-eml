# プライバシーとデータ

## データの保存場所

すべては1つのフォルダに入っています。LinuxとmacOSでは`~/.local-eml/`、Windowsでは`%USERPROFILE%\.local-eml\`です。

| パス | 内容 |
|---|---|
| `eml/` | メール。通常の`.eml`ファイルとして保存されます |
| `db/local-eml.db` | データベース。メールの詳細、検索インデックス、プロファイル、設定が入っています |
| `logs/local-eml.log` | ログファイル。件名とメールアドレスが含まれます。日付が変わると、その日のログは`local-eml-YYYY-MM-DD.log`に移され、30日より古いログは削除されます |
| `keys/secret.key` | 保存したIMAPパスワードの暗号化に使う鍵（システムに安全な保管場所がない場合）。それ以外の場合、鍵は資格情報マネージャー、キーチェーン、またはLinuxのSecret Serviceに`local-eml`という名前で保管され、`keys/`にはその旨を記したメモだけが置かれます |
| `session-token` | ブラウザがサインインに使うパスワード。[セッショントークン](./settings-cli#session-token)を参照してください |
| `prefs.json` | 起動時の設定（現在は一時セッションのスイッチのみ） |

このフォルダは同じコンピューターのほかのユーザーアカウントからは開けないように作成されます。

## ネットワーク

Local Emlは自分のコンピューター（`127.0.0.1`）からの接続だけを受け付けます。同じネットワーク上のほかの機器からは到達できず、ブラウザで開いているほかのWebサイトがLocal Emlと通信することもできません。インターネットに接続するのは、あなたが指示したときだけです。IMAPやS3のインポートとエクスポート、そして**設定 → このアプリについて**でのアップデート確認です。

## パスワードと鍵

- S3のシークレットキーとセッショントークンは保存されません。
- IMAPパスワードはプロファイルでバックグラウンド同期をオンにした場合にのみ保存され、その場合も暗号化されます。暗号鍵はシステムの安全な保管場所（資格情報マネージャー、キーチェーン、LinuxのSecret Service）に置かれ、それがない環境ではファイルに置かれます。[新着メールの受信](./sync#what-happens-to-your-password)を参照してください。
- サーバー名、バケット名、ユーザー名、アクセスキーIDは、秘密の情報ではないため、平文で保存されます。

## 一時セッション {#temporary-sessions}

いくつかの`.eml`ファイルを開いて中身を確認し、何も残さずに終わりたいときに使います。

**設定 → プライバシー → ダブルクリックでの起動を一時セッションにする**をオンにします。次回の起動から、ダブルクリックするたびに一時フォルダに空のライブラリを作って始まり、アプリを閉じるとそのフォルダは削除されます。アプリが異常終了した場合、残ったフォルダは次回の起動時に削除されます。ページ上部のバナーが一時セッションであることを知らせます。

残るファイルは、スイッチがオンであることを記憶する`prefs.json`だけです。メールもパスワードも含まれません。

一時セッションのウィンドウにある内容を残したい場合は、そのウィンドウの中でスイッチをオフにするか、同じページの**このウィンドウのメールを残す**をオンにします。ウィンドウを閉じるとき、メール、スター、既読状態、カテゴリは削除されずに、通常のライブラリへ追加されます。すでにライブラリにあったメールは元のマークを保ち、保存したプロファイルはパスワードを除いて、バックグラウンド同期がオフの状態で引き継がれます。閉じるときにこの処理を終えられなかった場合は、次回の起動時に完了します。

バックグラウンドサービスが動いている間は、このスイッチを使えません。サービスは終了しないためです。そのコンピューターではサービスを停止するか、`--ephemeral`を付けてLocal Emlを起動してください（または`LOCAL_EML_EPHEMERAL=1`を設定します）。こうすると、サービスのライブラリに触れない一時セッションが始まります。

## すべてのデータを削除する

**設定 → プライバシー → すべてのデータを今すぐ削除**は、すべてのメール、検索インデックス、インポート履歴、ログを削除します。ライブラリが再びいっぱいにならないよう、バックグラウンド同期もオフにします。プロファイル（パスワードを除く）、カテゴリ、設定、暗号化の鍵は残ります。実行する前に、確認用の言葉を入力する必要があります。

::: warning 削除したデータは元に戻せません
一時セッションと「すべてのデータを削除」は元に戻せません。Local Emlで削除したデータを復元することはできないので、必要なものはバックアップを取っておいてください。
:::
