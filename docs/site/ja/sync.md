# 新着メールの受信

Local Emlは保存したIMAPプロファイルの新着メールを自動で確認できます。この機能はオンにするまで動きません。また、プロファイルごとに個別にオンにします。

## オンにする

**インポート**ページで**IMAP**を選びます。保存したプロファイルはそれぞれスイッチの付いたカードとして表示されます。スイッチをオンにしてからカードをクリックし、パスワードを入力してインポートを1回実行します。それ以降は、Local Emlが自分でサインインし、前回の確認以降に届いたメールだけをダウンロードします。

各カードの点は現在の状態を示します。緑は、そのプロファイルがバックグラウンドで同期していることを意味します。黄色は、同期はオンになっているものの、パスワードを入力した最初のインポートを待っている状態です。

既定では10分ごとに確認します。この間隔はインポートページの**確認の間隔**で、1分ごとから1時間に1回までの範囲で変更できます。バックグラウンドサービスを使っている場合は、サービスの環境変数`LOCAL_EML_SYNC_INTERVAL`に`5m`や`30s`のような値を設定することもでき、`off`にすると一時停止します。両方が設定されている場合は、アプリ内の値が使われます。

## 即時配信

Gmail、Outlook、iCloud、Naverをはじめ、ほとんどのメールサーバーは、メールが届いた瞬間に接続中のアプリへ知らせることができます（IMAP IDLEと呼ばれる機能です）。プロファイルのサーバーが対応している場合、Local Emlはサーバーとの接続を1つ開いたままにし、次の確認を待たずに、1〜2秒以内に新着メールを取得します。10分ごとに自分で郵便受けを見に行くのではなく配達員が呼び鈴を鳴らしてくれるようなものです。

どちらの方式になっているかはカードに表示されます。

- **リアルタイム**：サーバーが新着メールを知らせ、Local Emlがすぐに取得します。
- **再接続中**：ネットワークが切り替わったなどの理由で、接続が切れました。Local Emlは失敗するたびに待ち時間を少しずつ延ばしながら自動で再接続し、その間に届いたメールも取得します。
- **間隔ごとに確認**：サーバーが新着メールを知らせられないため、これまでどおり間隔ごとに確認します。

監視されるのはプロファイルのフォルダ（通常はINBOX）だけです。通常の確認も念のため並行して動き続けます。確認の間隔を一時停止すると、即時配信も一時停止します。

新着メールが届くと、開いている**ライブラリ**ページは自動的に更新されます。新しい行はしばらくの間、色が付いて表示されるので、すぐに見つけられます。

## パスワードの扱い {#what-happens-to-your-password}

あなたの代わりにサインインするには、Local Emlがパスワードを保持しておく必要があります。同期をオンにすると、パスワードはAES-256-GCMで暗号化されてデータベースに保存されます。鍵はデータベースとは別に、システムの安全な保管場所に置かれます。Windowsの資格情報マネージャー、macOSのキーチェーン、LinuxのSecret Service（GNOME Keyring、KWallet）です。WSL、サーバー、コンテナではよくあることですが、そうした保管場所がない場合、鍵は自分のユーザーアカウントだけが読めるファイル`~/.local-eml/keys/secret.key`に保存されます。バックアップなどからデータベースのコピーだけを手に入れた人がいても、鍵がなければパスワードは読めません。

鍵がどこに保管されているかは**設定 → プライバシー**で確認できます。古いバージョンの鍵ファイルは、安全な保管場所が初めて使えるようになったときにそこへ移されます。鍵をファイルに置いておきたい場合は、`LOCAL_EML_KEYRING=off`を指定してLocal Emlを起動してください。その起動時に、鍵がファイルへ戻されます。

同期をオフにすると、保存されたパスワードが削除され、前回どこまで確認したかの記録も消えるため、アプリは先に確認を求めます。もう一度オンにするには、パスワードを入力してインポートを1回実行してください。

## 実行されるタイミング

- バックグラウンドサービス：コンピューターの電源が入っている間は常に。
- ダブルクリック：ウィンドウを開いている間だけ。
- 一時セッション：実行されません。起動をまたいで何も保持されないためです。

確認は毎回、インポートページにジョブとして表示されます。ほかのインポートと同じように、進行状況を確認したり、キャンセルしたりできます。

## 通知

新着メールが届いたときにデスクトップ通知を受け取りたい場合は、同期の設定にある**新着メールが届いたら通知する**をオンにします。既定ではオフです。初回はブラウザが許可を求めます。拒否すると、このオプションはオフのままになります。あとからブラウザのサイト設定で通知を許可し、もう一度オンにすることもできます。

通知はLocal Emlのタブから送られるため、受け取れるのはLocal Emlをブラウザで開いている間だけです。設定はブラウザごとに別々に記憶されます。迷惑メールまたはフィッシングとしてマークされたメールも件数には含まれますが、差出人と件名は表示されません。

通知をオンにしているのにポップアップが表示されない場合は、[新着メールの通知が表示されない](./troubleshooting#notifications)を参照してください。
