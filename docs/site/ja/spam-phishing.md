# 迷惑メールとフィッシング

Local Emlはフィッシングのように見えるメールについて警告します。また、自分でメールを迷惑メールやフィッシングとしてマークすることもできます。この2つは別々の機能です。

## フィッシングの警告

すべてのメールはフィッシングによく見られる特徴がないか、お使いのコンピューター上で調べられます。どこにも何も送信されず、疑わしい単語のリストにも頼りません。調べるのは次の点です。

- 表示テキストはあるWebサイトを示しているのに、実際には別のサイトへ移動するリンク
- Webサイト名ではなくIPアドレスに直接つながるリンク
- 別のサイトに似せて作られたWebサイト名、または見慣れない文字を使ったWebサイト名
- メールサーバーが行う送信者の確認（SPF、DKIM、DMARC）に失敗したメール
- 返信が差出人とは別のWebサイトに送られるメール
- 別のWebサイトのメールアドレスを含む差出人名
- 添付されたプログラムやスクリプト
- メール内のフォームやパスワード入力欄

メールにこれらのいずれかがあると、開いたときに黄色のバナーが表示され、一覧には警告アイコンが付きます。あくまで警告です。自動的に非表示になるものはありません。

問題のないメールだとわかっている場合は、バナーまたはマークのメニューで**迷惑メールではない**を選びます。そのメールの警告だけが消えます。警告を完全にオフにするには、**設定 → 迷惑メール・フィッシング**を開きます。

## メールを迷惑メールまたはフィッシングとしてマークする

メールを読んでいるときに盾のアイコンを使うと、**迷惑メール**または**フィッシング**としてマークできます。マークしたメールは次のように扱われます。

- ライブラリとスレッドに表示されなくなります。
- テキストのみで表示されます。書式、画像、添付ファイル、リンクはすべて無効になります。Local Emlがそれらの読み込み自体を拒否するので、何かが要求しようとしても無効のままです。

**設定 → 迷惑メール・フィッシング**には、マークしたすべてのメールが一覧表示され、そこでマークを解除できます。
